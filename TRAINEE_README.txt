TIB SAP TRAINING ASSISTANT — WINDOWS TRAINEE EDITION
Courses 1 + 2 + 3

FIRST USE
1. Save the ZIP to your Windows PC.
2. Right-click the ZIP and choose Extract All.
3. Open the extracted TIB_SAP_TRAINING_ASSISTANT_TRAINEE folder.
4. Double-click START_TIB_TRAINING_ASSISTANT.bat.
5. Choose your Course, Module and Lab, then start the lab.

IMPORTANT
- Do not run the application from inside the ZIP.
- Keep the content folder beside TIB_SAP_Training_Assistant.exe.
- No Python installation is required for trainees.
- Your progress is stored separately under your Windows user profile, so replacing the app folder does not intentionally erase progress.

LEARNING FLOW
READ -> LISTEN -> SHOW ME -> DO -> CONFIRM

LISTEN uses the narration supplied for the selected course/lab.
SHOW ME provides the course's visual/navigation guidance.
DO means perform the instructed activity in the live SAP/training environment.
CONFIRM means verify the expected result before continuing.

TROUBLESHOOTING
- If Windows blocks the downloaded ZIP, right-click the ZIP -> Properties -> Unblock (if shown) -> Apply, then Extract All again.
- If the app says content is missing, re-extract the entire ZIP. Do not move only the EXE.
- Run VERIFY_TRAINEE_PACKAGE.bat to confirm the EXE and all three course folders are present.
